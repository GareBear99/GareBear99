# GareBear99 Profile Snake Fixed Drop-in

This package contains the exact workflow path GitHub needs:

.github/workflows/generate-snake.yml

Do NOT upload the ZIP itself to the repo.

Use one of these methods:

## Method A — GitHub web UI

1. Open the ZIP on your computer.
2. In GitHub, go to GareBear99/GareBear99.
3. Click Add file -> Create new file.
4. Name the file exactly:
   .github/workflows/generate-snake.yml
5. Copy/paste the contents of .github/workflows/generate-snake.yml from this package.
6. Commit to main.
7. Go to Actions.
8. Run: Generate GitHub Contribution Snake.

## Method B — drag/drop folder

1. Extract this ZIP.
2. Drag the .github folder into the root of your repo locally.
3. Commit and push.
4. Run the workflow from Actions.

## README snippet

Paste the contents of README_SNAKE_SECTION_TO_PASTE.md into your profile README where you want the snake to show.

## Required repo setting

Settings -> Actions -> General -> Workflow permissions:
- Read and write permissions
- Save
