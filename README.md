# GareBear99 Snake Workflow Drop-in

Drag/drop the `.github` folder into the root of your `GareBear99/GareBear99` profile repo.

This adds:

.github/workflows/generate-snake.yml

After committing it:

1. Go to Actions.
2. Open "Generate GitHub Contribution Snake".
3. Click "Run workflow".
4. Wait for the `output` branch to be created.
5. Your README can load the SVG from:
   https://raw.githubusercontent.com/GareBear99/GareBear99/output/github-contribution-grid-snake.svg
